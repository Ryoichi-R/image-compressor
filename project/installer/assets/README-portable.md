# Image Compressor

このフォルダーの `ImageCompressor.App.exe` を起動してください。配布版に開発用BATは含まれません。

Windows x64／ARM64用の自己完結アプリです。フォルダー内のEXEは、入手した配布物のarchitectureに対応します。.NET SDKや別途の.NET runtimeは不要です。Windows 11での検証範囲・未実施項目は配布時の検証結果を確認してください。すべてのWindows版での動作確認を意味しません。この候補は未署名です。

1. ZIPを新しいフォルダーへすべて展開します。ZIP内から直接起動しないでください。
2. EXEを起動し、入力と別の出力フォルダーを指定します。
3. 一覧更新後、対象、形式、最大寸法、品質を確認して圧縮開始を選びます。容量指定の単位はKiB（1024bytes）です。
4. キャンセル時は処理の停止とボタンの復帰を待ちます。処理中に閉じる場合は確認画面の指示に従ってください。

`settings.json` がportable設定です。書込みできない場合は利用者のLocalAppData設定を使用します。設定を持ち運ぶ場合は必要な設定を保全し、他人の入出力パスを引き継がないでください。`settings.example.json` は初期値の見本です。

installer版の導入・更新は外側フォルダーのREADMEに従います。更新前にアプリを通常終了し、設定・利用者ファイルを保全してください。このフォルダーの手動上書きを更新手順として扱わないでください。
